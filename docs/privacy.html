白玉兰课件连播助手 · 隐私说明

适用版本：1.2.0 · 更新日期：2026 年 11 月 3 日

本扩展是独立开发的非官方播放器辅助工具，与白玉兰平台没有隶属或授权关系。它提供课件播放、静音、倍速和播完切课功能。

页面访问

扩展仅在 https://byljxjy.com/ 与 https://www.byljxjy.com/ 页面运行，访问视频元素、课件列表及可见提示框，以执行播放和切课操作。扩展不读取账号密码、Cookie、登录凭证、姓名、手机号、考试内容或其他浏览网站记录，也不直接提交学习或考试记录。

本机保存的设置

播放速度、静音和自动切课偏好通过浏览器扩展的本地存储保存，不使用云同步、不发送给开发者。卸载扩展会移除这些设置。扩展不会迁移或读取旧油猴脚本的存储。

错误日志

日志只记录当前页面内助手自身的操作事件、预定义错误类型和时间，不收集网页原始错误、账号信息、页面地址、课件名称或视频地址。最近 200 条记录保存在当前页面的内存中，刷新或关闭页面后清除，也可在面板中手动清空。

只有点击“导出日志”时才会在本机生成文本文件。报告包含扩展版本、播放设置、视频数量、音量、倍速和事件记录。导出的文件由你自行保管和决定是否分享；扩展不会自动上传日志。

网络与第三方

扩展不运行远程代码，不包含统计、广告或付费授权服务，不主动向开发者或第三方发送数据。课程视频与官网自身的网络行为由官网负责，适用官网的隐私规则。扩展更新通过你安装扩展的浏览器商店分发。

联系与变更

如有隐私或使用问题，请通过 GitHub Issues 或本扩展商店详情页的开发者支持入口联系发布者。本说明如发生变更，将随版本更新。
